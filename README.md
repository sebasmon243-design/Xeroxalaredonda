# Vehicle Presets (YimMenu, Lua)

`vehicle_presets.lua`: spawnea un vehiculo por nombre, aplica pintura, rines y nivel de mejora,
y guarda/carga presets en `%appdata%\YimMenu\vehicle_presets\<nombre>.json` (un archivo .json por vehiculo).

Instalacion: copiar el .lua a `%appdata%\YimMenu\scripts\` y recargar los scripts en YimMenu.
Aviso: usar YimMenu en GTA Online puede causar baneos.

La carpeta `vehicle_presets/` del repo trae presets de ejemplo; copiala a `%appdata%\YimMenu\` y carga cada uno escribiendo su nombre (ej. `adder_rojo`).
